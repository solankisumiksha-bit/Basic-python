# Module 4: Functions & Modules in Python

This module contains two Python programs demonstrating the use of **functions**, **loops**, and the built-in **math module**.

## Tasks

### Task 1: Calculate Factorial Using a Function

The program defines a function named `factorial()` that takes a number as an argument, calculates its factorial using a loop, and returns the result.

**File:** `task1_factorial.py`

### Task 2: Using the Math Module for Calculations

The program asks the user to enter a number and uses Python's `math` module to calculate:

* Square root
* Natural logarithm (log base e)
* Sine of the number in radians

**File:** `task2_math_calculations.py`

## How to Run

### Step 1: Install Python

Make sure Python 3 is installed on your computer.

Check the Python version using:

```bash
python --version
```

### Step 2: Open the Project Folder

Open Command Prompt or Terminal and navigate to the folder containing the Python files:

```bash
cd path/to/project
```

### Step 3: Run Task 1

Run the factorial program:

```bash
python task1_factorial.py
```

**Expected Output:**

```text
Factorial of 5 is: 120
```

### Step 4: Run Task 2

Run the math calculations program:

```bash
python task2_math_calculations.py
```

Enter a positive number when prompted.

**Example:**

```text
Enter a number: 5
Square root: 2.23606797749979
Natural logarithm: 1.6094379124341003
Sine (in radians): -0.9589242746631385
```

## Requirements

* Python 3.x
* No external packages are required.
* The `math` module is included with Python.

## Important Note

For Task 2, the square root and natural logarithm calculations require the input number to be greater than `0`.
