# Module 2: Basic Python Concepts

## 📌 Overview

This module focuses on understanding basic Python programming concepts such as user input, variables, arithmetic operations, string concatenation, and conditional statements.

## 📝 Tasks

### Task 1: Perform Basic Mathematical Operations

The program:
- Takes two numbers from the user.
- Performs addition.
- Performs subtraction.
- Performs multiplication.
- Performs division.
- Handles division by zero.

### Task 2: Create a Personalized Greeting

The program:
- Takes the user's first name.
- Takes the user's last name.
- Combines both names into a full name.
- Displays a personalized greeting.

- Python 3
